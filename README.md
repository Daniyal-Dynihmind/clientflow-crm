# ClientFlow CRM 🚀

> A modern, professional CRM and Invoicing platform built for digital agencies and freelancers.

## 📌 Project Overview

ClientFlow is a Micro-SaaS web application that helps freelancers and small agencies manage their clients, track business pipelines, and create professional invoices, all from a single dashboard.

**Problem:** Freelancers and agencies often manage clients in spreadsheets, invoices in random templates, and payments in messages. This causes lost clients, late payments and an unprofessional image.

**Solution:** ClientFlow brings everything into one clean dashboard.

## ✨ Key Features

- 📊 **Dashboard** – Revenue KPIs, analytics chart and recent activity feed
- 👥 **Client CRM** – Manage clients with status (Lead, Active, Completed)
- 🧾 **Invoice Builder** – Create invoices with live A4 preview
- 🖨️ **Print / PDF** – Download or print professional invoices
- ⚙️ **Settings** – Agency profile and branding
- 💾 **LocalStorage** – Data is saved in the browser, no login needed

## 🛠️ Tech Stack

- HTML5, CSS3 (Tailwind CSS via CDN)
- Vanilla JavaScript
- LocalStorage for data persistence
